# General settings style sample

Standalone interactive design review; it does not change app preferences or the iOS implementation. Open index.html.

Uses the desktop Settings.css and dark theme tokens. All text uses the app’s system sans-serif typography with normal letter spacing. Section headings use normal capitalization. Current iOS General controls are arranged as bordered desktop panels, with headings inside, row dividers, right-aligned controls and desktop-sized toggles. Preview supports 402×874 and 390×844 layouts. The app header and floating navigation remain in their mobile positions.

Desktop sources: Moku/src/lib/components/settings/Settings.css, sections/GeneralSettings.svelte, src/app.css and src/lib/styles/themes.css.
