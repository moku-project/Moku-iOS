# Recent and Tracking mockups

Design proposals using sample data; no app code has changed. SVG sources and PNG screenshots are included.

## Recent
History and Updates reuse Extensions’ compact rows, section picker, overflow actions, media tabs, and floating navigation/tools. History shows grouped chapters and resume progress. Updates shows unread chapters, downloads, and resume actions. Search, update refresh, and clear-history confirmation belong in the tools menu; title actions belong in row overflow menus.

## Tracking
Service rows expose connection status and AniList import. MyAnimeList remains Coming soon, matching desktop availability. Connect/disconnect and authorization should use popups with dimmed/blurred backgrounds, including the desktop copy-link and paste-token fallback.

The import setup popup chooses media, list statuses, and an installed source or source-less import. Review shows automatic matches, manual match correction, skipping, already-saved items, dry run, and a persistent import action. Desktop parity also requires resumable matching/import, progress, failed-item retry/export, and completion states, which are not separately illustrated here.

These are layout previews, not a claim that desktop feature parity has been implemented.
